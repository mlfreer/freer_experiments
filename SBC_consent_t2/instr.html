In this study, you evaluate a lottery ticket consisting of two lotteries. Each has two equally likely outcomes, determined by two independent virtual coin flips.

1
Lottery 1 Pays £{{ session.config.A_BAR }} if the first coin is heads, and £{{ participant.x_draw }} if tails.
2
Lottery 2 Pays £{{ session.config.A_BAR }} if the second coin is heads, and £0 if tails.

Your lottery ticket earnings equal the sum of both lottery outcomes. For example:

  • First coin tails, second coin tails → £{{ participant.x_draw }} + £0 = £{{ participant.x_draw }}
  • First coin heads, second coin tails → £{{ session.config.A_BAR }} + £0 = £{{ session.config.A_BAR }}
