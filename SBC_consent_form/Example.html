Example.

In this example, you will work through an example calculation of your possible bonus payments.

For this example, imagine that in Part 2, the coin flip for Lottery 1 results in heads and the coin flip for Lottery 2 results in tails.

For each question, please calculate the bonus payment you would receive if that decision were randomly selected for your bonus payment. You can only proceed if you answer all questions correctly.

Lottery 1 Pays £{{ session.config.A_BAR }} if the first coin flip is heads, and £{{ participant.x_draw }} if tails.
Lottery 2 Pays £{{ session.config.A_BAR }} if the second coin flip is heads, and £0 if tails.
